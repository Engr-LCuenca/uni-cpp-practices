# Caesar Cipher Text Shift

A polished C++ console application that implements the classic Caesar cipher for both encryption and decryption.

## Overview

This project demonstrates strong fundamentals in string handling, character classification, and modular arithmetic. It shifts alphabetic characters by a chosen value while preserving spaces and other non-letter characters.

## Features

- Encrypt text with a custom shift value
- Decrypt text using the same shift value
- Preserve spaces and non-alphabetic characters
- Support both uppercase and lowercase letters
- Simple interactive menu-based interface

## How to Run

Compile the program with:

```bash
g++ Caesar_cipher.cpp -o Caesar_cipher
```

Run it with:

```bash
./Caesar_cipher
```

## Example

Choose option 1, then enter:

```text
Hello World!
3
```

Output:

```text
Encrypted text: Khoor Zruog!
```
