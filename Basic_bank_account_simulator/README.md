# Basic Bank Account Simulator

A simple C++ console application that simulates a basic bank account with deposit, withdrawal, and balance-check features.

## Overview

This project demonstrates how to model a bank account using a class in C++. The program allows the user to:

- create an account with an owner name and initial balance,
- deposit money,
- withdraw money,
- view the current balance.

## Features

- Create an account with a name and initial balance
- Deposit money securely
- Withdraw money with balance validation
- Prevent invalid or negative amounts
- Display the current balance with formatted output

## How to Run

Compile the program with:

```bash
g++ Basic_bank.cpp -o Basic_bank
```

Run it with:

```bash
./Basic_bank
```

## Example Flow

1. Enter the account owner name.
2. Enter the initial balance.
3. Choose an action from the menu:
   - deposit,
   - withdraw,
   - view balance,
   - exit.

## Purpose

This project is intended as a daily C++ practice exercise focused on:

- classes and objects
- encapsulation
- input validation
- basic console application design
